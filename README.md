# Project_C_CarParking_2025
Simulateur de parking en temps réel développé en langage C, avec un affichage entièrement en console (terminal Linux). Le projet reproduit la logique d'un parking payant : gestion des entrées/sorties par barrières, distribution de tickets, calcul des frais de stationnement, et circulation autonome de véhicules à la recherche d'une place libre
